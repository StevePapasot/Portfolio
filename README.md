# Stavros Papasotiropoulos — Mission Console Portfolio

A scroll-driven, interactive 3D portfolio built with Three.js, GSAP ScrollTrigger, and pure HTML/CSS/JS.

## Features
- Scroll-driven camera flight through a holographic OSINT node network
- Live SOC threat feed, dual clocks, telemetry radar
- Konami code hidden terminal (↑↑↓↓←→←→BA)
- Clickable 3D project nodes with detail cards
- Horizontal pinned toolkit gallery
- Drag-to-rotate OSINT explorer

## Stack
Three.js · GSAP · ScrollTrigger · Chakra Petch · JetBrains Mono
